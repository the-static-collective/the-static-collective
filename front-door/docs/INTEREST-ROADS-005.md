# INTEREST-ROADS-005 — Source-owned public context beside the human Porch

**Status: staged draft implementation on top of ATTENTION-FLOW-004; no public matching, permission, or field proof.**

## What already existed

This change does **not** create another community database. It composes two *independent source-owned public indexes*:

1. **JAR;VIS** `commons/recent-work-v1.json`, release `RECENT-2026-10-28-008`, reviewed 2026-10-28, Git blob `4faa7039c0ce74afa7fc623020619a124b859f4c`. Its entries name public research, prototypes and technical source doors, with status and pinned source links. Its JAR;VIS selection machinery remains owner-local.
2. **planZ** `public/attention-v1.json`, edition `ATTENTION-2026-10-28-005`, reviewed 2026-10-28, Git blob `49e70c0caeaf0bca430338829b69d51c8c617385`. Its entries describe open project plan gates; all included entries explicitly refuse verified field outcome, execution permission and third-party approval.

The Porch now carries a **dated static, local derivative** of these two public documents, at `porch/interest-roads-v1.json`. Its provenance is preserved per source, its catalog status says `SOURCE_PINNED_EDITORIAL_SNAPSHOT_NOT_LIVE_AVAILABILITY`, and every entry keeps its public URL and original source link. This index is not a new authority or claim of consent.

The derivative is a bounded public lookup, not a live sync or an independent source of truth. When owners publish updates, manually review original source documents and advertised URLs before regenerating or replacing this snapshot. Never update the review date without reviewing the source. A Git blob hash identifies file content, **not** an authoritative endorsement of the entries.

## The real executable seam

```text
visitor freely writes one note
   +
temporary attention choice (glance / few / longer)
           ↓
local first-action compiler (NEXT-MOVE-003 / 004)
           +
fixed same-origin public research snapshot
           ↓
read-only interest matching in browser only
           ↓
up to 3 related documented experiments
up to 1 open planZ research question
           ↓
visitor may inspect a source or ignore them all
```

This adds a source-backed **context lane**, not human matching. The visitor's original note, approximate area, selected attention window, and any private receipt key do not become query parameters, recommendation logs, an external request, or a persistent profile. The only new fetch is the literal constant path `/porch/interest-roads-v1.json`; no visitor text crosses that request.

Interest matching uses explicit source `tags` (with a few transparent common-word aliases). A handful of technical atlas/index entries require relevant technical intent so that someone who mentions bread sees the Garden rather than an unrelated repository map. The owner source's editorial order breaks ties. This ranking makes **no** claim about people, available volunteers, suitability for safety-critical help, geographic proximity, or service quality. The browser renders source-controlled text as `textContent`, never injected HTML.

The related documents section is supplemental. The one-small-move card still works if the catalog is absent, invalid, stale, or irrelevant. The section reports HOLD rather than fabricating a match.

## Why this matters to the architecture

- **JAR;VIS:** its reviewed public work feed supplies useful context, not a global assignment engine or access to its operator journal.
- **planZ:** separately owned public research gates remain `NOT_VERIFIED`, not promises to execute tasks.
- **GRAFT:** future audited tools could rebuild or pin an updated public projection, with explicit source ancestry. No GRAFT reader is being launched in the public page.
- **webZ / reLATTE:** future voluntary crossing of a note, work card or method can use their source-owned contracts; this change has no crossing signatures or automatic receiver admission.
- **BananaSpork / Garden:** can later receive an *explicitly accepted* community task under their own access rules. A topical keyword here grants them no task or permission.
- **Haunted Toaster / LemonPRESS:** an explicitly permitted outcome might later become a small celebratory print or song. There is no current automatic pipeline or publication.

The current experiment proves a small composition of independent **public research surfaces** into a readable next-action experience. The field-action layer remains a separate authority/verification gate.

## Test scenarios

1. Food / bread / garden: relevant published Garden description and an unapproved planZ food-table question, not a helper assignment.
2. Music / festival: relevant Jubilee and musical prototypes, plus the separately proposed Jubilee plan gate.
3. Email / farm: a documented COMMUTER integration prototype; not an actual farm integration.
4. Unrecognized query: **no source recommendation** and a still-working local first action.
5. Malformed feed, counterfeit execution approval, insecure URL: fail to no suggestions.
6. Approximate area change alone: **no fabricated proximity**.
7. Editing/reset during pending load: a stale result cannot repaint a new note.
8. DOM safety: source text never parsed as HTML; user text never transmitted to a search endpoint.

Commands: `cd front-door && node --test porch/*.test.mjs && python3 -m unittest discover -s tests -v`. Mobile browser and source-link/HTTP acceptance checks are still required before promotion.
