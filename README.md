# The Static Collective

**A public creative and research laboratory.**

We make **music, software, research instruments, playable worlds, community tools, and strangely named machines** — in public — while returning to one question:

> **How can something genuinely change without losing where it came from?**

The short version: this is a growing experiment in **attributable transformation**. Things are allowed to mutate, remix, cross disciplines, and become weird. We try to keep enough provenance, evidence, and human authority intact that you can still tell what happened.

## A few laws we keep finding

```text
fact           != inference
proposal       != acceptance
representation != occurrence
compatibility  != authority
public         != canonical
```

Different repositories have different authority. A README can orient you without becoming the source of truth for everything it points at.

## What connects all this?

A song can become a video instrument.

A research note can become executable mathematics.

A game mechanic can become a way to think about memory, identity, or relationship.

A strange metaphor can become software.

But the transformation is more useful when we can still ask:

1. **What was the original particular?**
2. **What changed?**
3. **What relation survived the change?**
4. **What evidence lets somebody inspect it?**
5. **Who still has authority over the thing?**

That is the connective tissue.

## You do not need to understand everything

The repository names are history, not prerequisites.

Pick a door that looks interesting. Follow it until it stops being useful. Leave a trace if you find something worth keeping.

**Keep the weird particulars. Build better apertures between them.**
